# VeriSim Pro — AgentUI/vhtml 版说明

本目录已适配为 AgentUI 组件页面，不再作为独立 HTML demo 运行。页面通过平台路由访问：`/a/{agent_id}/i`。

## 界面文案（i18n）
界面双语（zh-CN/en-US），文案集中在 `langs.json`（扁平 key），由平台 env.js 自动加载到 `$mod.$i18n`，语言跟随平台设置。模板用 `{{ $t('key') }}`；控制台日志统一存 thunk（`() => $t('key', params)`，见 setup 中的 `tt`——注意必须用 `=` 声明注册到 `$data`，`const` 是 setup 私有的，初始化脚本访问不到），渲染时才翻译，切换语言时历史日志也同步刷新。界面不出现引擎名、模块名、镜像源、内部事件名等后台机制关键词。

## 布局
页面为上/中/下三层：
- 上：统一 header。顺序为「仿真 / 综合」按钮、「代码预览 / 波形 / 原理图 / 综合报告 / 门级网表」标签页、「会话文件 / 加载示例 / 顶层模块 / 打开 AI / 运行状态」。header 使用 `flex-wrap`，宽度不足时自动折成两行。会话文件通过 `GET $mod.fs_prefix + '/sessions/' + aiSessionId` 读取目录，仅列出 `.v/.sv/.txt` 文件。
- 中：工作区 + 对话组件。PC 模式并排展示；移动端对话组件默认隐藏，点击「打开 AI」后从右侧划出，并可用面板内 × 关闭。
- 下：控制台，固定显示；无独立 section-head，控制台右上角提供浮动「复制」和「清空」按钮。

## 架构
- `index.html`：vhtml 页面。包含界面结构、轻量代码编辑区、控制台、波形绘制、原理图交互、综合报告、ai-box 与 ui_run 事件订阅。
- `js/examples.js`：内置单文件 Verilog 示例。
- `js/engines.js`：Icarus Verilog WASM 仿真（主线程）与 Yosys WASM 综合（Web Worker 异步执行，不阻塞 UI）。
- `js/yosys-worker.js`：Yosys 综合 Web Worker，负责加载 Yosys WASM 并在独立线程中运行综合计算。
- `js/vcd.js`：VCD 解析。
- `js/synth.js`：顶层模块推断与 Yosys stat 解析。
- `iverilog/`、`yosys/`、`vendor/`：WASM 引擎与原理图渲染库的**本地副本**，仅作为 CDN 不可达时的回退（离线/内网部署）。云端部署时可整体删除以节省 ~55MB 存储。

## 引擎加载策略（镜像源列表，国内优先）
所有大体积引擎/资源的来源统一配置在 **`js/sources.js`**（`MIRRORS` 镜像表 + `RESOURCES` 资源表）。换源/加源只改这个文件，不动加载逻辑。每个资源按列表依次尝试，**服务器相对地址永远是最后一个兜底源**：

1. 国内镜像 → 2. 海外镜像 → 3. 服务器本地文件

| 资源 | ① 国内 | ② 海外 | ③ 本地回退 |
|---|---|---|---|
| Icarus Verilog（ivlpp/ivl/vvp） | jsdmirror gh `verisim@a275a9a` | jsDelivr gh 同仓库 | `iverilog/` |
| elk / netlistsvg（原理图） | 同上 | 同上 | `vendor/` |
| NanGate 45nm Liberty | jsdmirror gh `ORFS@aaf99bf` | jsDelivr gh 同仓库 | `libs/NangateOpenCellLibrary_typical.lib` |
| Yosys（bundle + ~47MB wasm/tar） | 无可用国内公共源（见 sources.js 注释） | jsDelivr npm `@yowasp/yosys@0.64.1130` | `yosys/gen/` |

缓存层级：内存缓存 → 浏览器缓存（Liberty 走 IndexedDB，引擎走 HTTP 缓存）→ 镜像列表 → 本地文件。控制台显示每个组件实际来自哪个源（如「引擎 ivlpp：来自 cn_jsdmirror_gh」）。

给 Yosys 加国内源的方法：把 `yosys/gen` 目录推到自己的 GitHub 仓库，在 `sources.js` 的 MIRRORS 加一行 `cn_myrepo_yosys: 'https://cdn.jsdmirror.com/gh/<user>/<repo>@<sha>'`，并把 `RESOURCES.yosys.mirrors` 改为 `['cn_myrepo_yosys', 'jsdelivr_npm']`。

## 使用
1. 在「代码预览」标签页直接编辑 Verilog，或从顶部「加载示例」选择示例。
2. 点「仿真」按单文件源码运行 Icarus Verilog；代码中没有 `$dumpfile` 时会自动注入 `__vcd_dump__`。
3. 点「综合」运行 Yosys；单文件源码中的测试台模块（`tb`、`*_tb`、含 `$display/$finish/$dump*` 的模块）会先被剔除，再查看 stat 报告、门级网表与 netlistsvg 原理图。原理图支持左上角 −/＋/适应 按钮，也支持滚轮缩放和拖动平移；移动端波形信号列会改为上下布局。

## 工艺选择
header 中「工艺」下拉决定综合目标，选择会持久化到 localStorage：

- **通用 techmap**（默认）：Yosys 内置通用门（`$_AND_`/`$_DFF_P_` 等），脚本 `proc; opt; fsm; memory; techmap`。
- **FPGA 工艺**：iCE40 / ECP5 / Nexus / Gowin / Xilinx / GateMate / Intel ALM / Anlogic / Efinix / SF2-IGLOO2 / GreenPAK4 / CoolRunner-II。单元定义已内置在 `yosys/gen/yosys-resources.0.tar`，脚本换成 `synth_<arch> -top <name>`，报告直接显示厂商原语（如 `SB_LUT4`、`TRELLIS_FF`）。
- **ASIC Liberty**：
  - `NanGate 45nm（内置）`：读取 `ui/libs/NangateOpenCellLibrary_typical.lib`（静态部署，需预先下载放入），流程 `read_liberty -lib → synth → dfflibmap -liberty → abc -liberty`。
  - 「导入 .lib」按钮：用户选择本地 Liberty 文件，只写入浏览器 IndexedDB（库名 verisim-libs），**不上传服务器**；缓存的工艺以「（本机缓存）」出现在下拉里，选中时出现「删工艺」按钮可移除。单个文件上限 40MB。
- 单元映射表与 DFF 统计兼容通用门、FPGA 原语与 ASIC 单元（`DFF*`/sky130 `dfxtp` 等）。
4. 右侧 AI 助手通过 `<ai-box v:id="aiSessionId">` 固定显示；session id 会保存到 localStorage，刷新后继续绑定上一次对话。

## ui_run 事件
前端在当前 ai-box session 上订阅：
- `sim_code --code <source> [--top <name>] [--pane wave]`
- `sim_file --file <ufs_path> [--tb <ufs_path>] [--top <name>] [--pane wave]`（路径支持 `$SESSION`/`$AGENT` 前缀）
- `synth_file --file <ufs_path> [--top <name>] [--pane synth]`（路径支持 `$SESSION`/`$AGENT` 前缀）
- `show_pane --pane code|wave|sch|synth|netlist|console`
- `clear_console`

`sim_file` 会通过 `GET $mod.fs_prefix + '[' + ufs_path + ']'` 读取文件内容，然后转调 `sim_code` 逻辑；最终代码会同步到「代码预览」并保存到 localStorage。

## 结果组与本地恢复
「波形 / 原理图 / 综合报告 / 门级网表」视为同一个结果组，顶部会显示 `当前结果组：来源 · code hash`。切换示例、调用 `sim_code` / `sim_file` / `synth_file` 或手动运行导致代码版本变化时，会先清空这四个结果页；普通文本编辑不会清空。

页面只把 `code`、`ai_session_id`、`tech` 保存到 localStorage；四个结果页不做缓存。刷新后**一律回到「代码预览」页**（不恢复上次标签页，避免落在空白的结果页），编辑器中是最后一次运行使用的源码（若运行后又输入了新代码，则保留最新输入）。结果组需要重新运行仿真/综合。
