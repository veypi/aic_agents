ReliaScope 是什么 · 快速上手 AgentDB 驱动

软件可靠性验证平台：多源采集故障数据 → 原始样本驱动指标计算 → 单目标验证自动判定 → 报告归档，全流程数据可追溯。
1接入与采集采集接口将日志 / APM / 混沌实验等故障数据汇入 failures 原始样本表（未接入时可手动录入或 CSV 导入）。
2验证与判定λ、MTBF、R(720h) 前端实时计算，判据逐条核对，结论卡即时生成。
3报告与归档Agent 生成图文报告数据，前端渲染可视化报告；CSV 数据包随时导出归档。
数据底座（12 张表）：softwares 软件资产 · failures 原始故障样本（全部指标唯一数据源）· incidents 故障工单 · criteria 验证判据 · reports/report_sections 报告与内容块 · channels 采集通道 · events 事件流 · model_metrics/predictions Agent 模型与预测产物 · quality_runs 质量评估 · integrations 外部接入。

三层架构：数据从哪来 设计原则

前端只有两种角色——根据数据库实时计算、根据数据库渲染；一切异步产物都经 AgentDB 流向页面。
① 前端实时计算点击、筛选、录入后必须即时反馈的：KPI、判据核对、趋势/分布/拟合曲线、CSV 导入导出。
② Agent 后台任务可异步的重计算与撰写：模型重训、质量评估、报告生成、根因分析、全通道同步。前端 POST /api/tasks 触发，Agent 写库。
③ 外部系统对接探针 / CI-CD / APM / 告警等真实数据源由后台采集器写库（integrations 表查看接入状态），前端代码无需改动。

数据交换

CSV 导入导出格式 单目标验证页

「导出数据包 CSV」归档当前对象全套数据；「导入样本 CSV」批量录入故障样本；两者格式兼容，可直接整包回导。
导出结构（单文件三段）
① 对象信息 + 指标汇总（T、n、λ、MTBF 及置信区间、R(720h)、可用度 A）
② 判据逐条核对 + 验证结论
③ 原始故障样本表
文件带 BOM，Excel / WPS 直接打开不乱码。
导入规则
· 必需列：间隔Δt(h)、故障模式
· 可选列：严重度（致命/严重/一般/轻微，缺省一般）、构建（缺省 B5）、计入统计（“否”=剔除，缺省计入）
· seq 按当前最大值自动续号；非法行自动跳过并计数
· UTF-8 / GBK 编码均可识别
样本列含义导入要求
seq失效序号导出列，导入时忽略（自动续号）
发生时刻(h)累计试验时间导出列，导入时忽略（由 Δt 累加）
间隔Δt(h)距上次失效的小时数必填，正数
故障模式如 内存泄漏 / 并发竞态必填，非空文本
严重度致命 / 严重 / 一般 / 轻微可选，缺省“一般”
构建构建版本号，如 B5可选，缺省 B5
计入统计是 / 否可选，缺省“是”

权限与可见性

· 平台设置（菜单“系统”分组）仅管理员可见：菜单项按 PermAdmin 权限自动显示或隐藏。
· 业务表数据按登录用户隔离，不同用户互不可见。
· 判据中标记 强制 的条目（如 P1 严重故障一票否决）不可停用；阈值修改后所有验证对象即时按新标准重判。
· 驾驶舱「实时事件流」读取 events 表：采集接口或 Agent 任务写入后自动呈现，空表时显示等待占位。
